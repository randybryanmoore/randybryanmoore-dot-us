How the one-pager lifecycle is counted
  • One-Pager Local: page-specific source exists only in the working checkout.
  • One-Pager Committed / Pushed: the OP release is checkpointed locally / uploaded to the shared repository.
  • One-Pager Deployed / Live: the OP release entered Pages / was read back from its public URL.
  • Parent Dossier: hosting and shared-code context only; it is not the one-pager's active version number.
